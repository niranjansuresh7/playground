# playground

A personal sandbox for experiments, prototypes, and learning. Code here is
exploratory: some ideas grow into real projects, others get thrown away.

## Purpose

- Try out new languages, libraries, and tools
- Build small prototypes and proof-of-concept ideas
- Keep notes and snippets worth coming back to

## Structure

Each experiment lives in its own folder at the top level, with its own short
README explaining what it is and how to run it.

```
playground/
├── README.md
└── <experiment-name>/
    ├── README.md
    └── ...
```

## Getting started

Clone the repository:

```bash
git clone https://github.com/niranjansuresh7/playground.git
```

```bash
cd playground
```

Then open any experiment folder and follow the instructions in its README.

## Conventions

- One folder per experiment, named in `kebab-case`
- Each folder has a README with a one-line description and run steps
- Nothing here is guaranteed to be stable or maintained
